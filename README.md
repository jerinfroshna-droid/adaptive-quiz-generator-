# Adaptive Quiz Generator AI

## 📌 Project Overview

Adaptive Quiz Generator AI is an AI-powered educational application that automatically creates quizzes from study materials.

Students can upload a PDF, and the system uses AI to generate multiple-choice questions based on the uploaded content.

The system also evaluates student answers and adapts the difficulty level according to their performance.

---

## 🎯 Objectives

- Automate quiz generation from study materials.
- Reduce manual question preparation.
- Provide instant answer evaluation.
- Give students personalized difficulty levels.
- Improve self-assessment and learning.

---

## ✨ Key Features

- 📄 PDF study material upload
- 🤖 AI-based MCQ generation
- 🎯 Multiple difficulty levels
- ✅ Automatic answer evaluation
- 📊 Score and percentage calculation
- 💡 Answer explanations
- 🧠 Adaptive difficulty
- 📚 Quiz history

## 🧠 Adaptive Learning

The system adjusts the difficulty of the next quiz based on the student's performance.

| Score | Difficulty Action |
|---|---|
| 80–100% | Increase difficulty |
| 50–79% | Maintain difficulty |
| Below 50% | Reduce difficulty |
